# Anime Paradise — Waifu Gacha & Dating Sim

Уютная коллекционная 2D-игра на движке **Godot Engine 4** с клиент-серверной архитектурой на **Python FastAPI**.

## Ключевые Возможности
- 🎰 **Кейсы и Лутбоксы (Gacha):** честный серверный RNG, гарант (SR каждые 10 круток, SSR каждые 60), система конвертации дубликатов в осколки.
- 💖 **Коллекция и Вайфу:** популярные героини (*Райдэн*, *Рем*, *Аска*, *Сейбер*, *Ху Тао*, *Эмилия*, *Рей*, *Йор*, *Хината*, *Мику*).
- 👗 **Гардероб (Wardrobe):** разблокировка и смена нарядов для героинь.
- 🏠 **Общежитие (Dormitory):** 2D-комната с чиби-персонажами, расстановка мебели, поглаживание по голове, кормление любимыми блюдами и пассивный сбор монет.
- 🌸 **Симулятор Свиданий (Dating VN):** визуальная новелла с интерактивными выборами в локациях (Парк сакуры, Кафе, Фестиваль, Библиотека), разблокировка романтических CG-иллюстраций.
- 🛍️ **Магазин:** покупка еды, сладостей и мебели за монеты и кристаллы любви.

## Быстрый запуск

### 1. Запуск Сервера (Backend)
Требуется установленный Python 3.11+ и пакетный менеджер `uv`.

Просто запустите файл `start_server.bat` или выполните команды в терминале:
```bash
cd server
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```
- API доступно по адресу: http://127.0.0.1:8000
- Документация Swagger UI: http://127.0.0.1:8000/docs

Для запуска автоматических тестов:
```bash
cd server
uv run pytest -s
```

### 2. Запуск Клиента (Godot 4)
1. Откройте **Godot Engine 4** (версии 4.2 или 4.3).
2. Нажмите **Import** (Импортировать) и выберите файл `client/project.godot`.
3. Нажмите **Play** (F5), чтобы запустить игру.

При первом входе можно нажать **«⚡ Быстрый гостевой вход»**, чтобы мгновенно получить стартовые 2000 монет и 60 гемов и приступить к крутке кейсов!
